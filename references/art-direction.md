# 镜头和质感调试

| 目标 | 可实现的动作 | 验收画面 |
|---|---|---|
| 有速度或冲击 | 在主体附近布置能掠过的前景，沿轨迹推动相机，在动作时点给短促反馈 | 主体清楚，近景的视差能读出来 |
| 有重量 | 统一尺度，让接触点、重心变化、压缩或回弹从同一动作曲线派生 | 定格时能指出接触面和支撑方向 |
| 有精密感 | 倒角承接高光，用粗糙度区分拉丝金属、陶瓷和磨砂部件 | 静止画面也能辨认材质和结构 |
| 有空间层次 | 安排前景遮挡、中景主体和背景轮廓，再选雾与主辅光颜色 | 缩小画面时主体仍能从背景分离 |
| 有叙事 | 远景解释关系，近景给出动作因果，下一镜接住动作结果 | 每个切点前后能说明观众看到什么变化 |

用镜头表记录 **时间段 / 主体动作 / 相机从哪看向哪 / 画面重心 / 切点条件**。焦点、视野、遮挡和背景都要在目标画幅下检查。通过位置、目标和视野参数描述镜头。

## 资产、材质和后期

- 近景先优化轮廓、厚度、圆角、细缝和比例。GLB 中保留活动节点，检查世界尺度、正面轴、枢轴和地面接触。
- PBR 材质需要反射环境与明暗对比。金属先布置可反射的软光源或环境贴图，再微调金属度、粗糙度和曝光。基色图片通常标为 sRGB，金属度、粗糙度和法线使用数据贴图。
- 局部积水、抛光部件和灯罩应各有反射强度。平面反射可用镜像相机或 Reflector 做额外渲染通道。按视角和表面遮罩混合，先控制亮度和覆盖范围。
- 泛光让高亮灯具溢出少量光，留住中间调纹理。最终色调映射和输出色彩转换保持在正确的渲染阶段。[Three.js OutputPass 文档](https://threejs.org/docs/pages/OutputPass.html)
- 运动模糊有明确来源。先用镜头移动和前景视差建立速度感，再按需求加入速度或子帧模糊。模糊掩盖主体动作时，减少强度或缩小影响区域。
- 粒子按动作事件的时间、发射点、速度和寿命生成。声音也以动作时点为基准。升降速、冲击和停顿能解释动作。

## 代表帧的修订顺序

先关掉后期看画面。主体发暗时检查灯光方向和材质反射。轮廓淹没时改背景与机位。接地不实则检查实际坐标和阴影。场景成立后逐项开启后期，每次都看效果有没有帮助读懂动作。代表帧通过以后，用短样连看切点与节奏。

具名主体在近景中应能凭外形辨认。选两三个能看清差异的视角，用最终景别核对主要比例与曲面过渡。一个动作看起来只在画面中央旋转时，先看固定机位的短样。让主体经过明确的空间参照，确认它的方向与位移都读得出来。
