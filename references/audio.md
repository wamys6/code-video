# 对白与音轨

影片可选填 `film.audioClips`。预览与导出使用同一份离线混音，画面与口形使用同一条时间轴。输入可以是本地的对白、音乐和音效，模板默认将它们混成一条 48 kHz 立体声 Opus 音轨。

## 内嵌音频

构建时反复使用 `--audio 名称=文件`。构建器把文件放入 `audioAssets` 并内嵌到 HTML。接受 WAV、MP3、OGG、Opus、M4A 和 WebM 文件。实际解码能力取决于浏览器与文件内部编码，可先用 WAV 验证。

```js
const film = {
  title: '对白样片', width: 1280, height: 720, fps: 30, frameCount: 240,
  audioClips: [
    { src: audioAssets.line, at: 1.20, offset: .15, duration: 2.10, gain: .9 },
    { src: audioAssets.room, at: 0, gain: .18 },
  ],
};
```

- `at` 是素材进入影片的秒数，默认 0。`offset` 是素材内部裁切的起点，默认 0。
- `duration` 是使用的秒数。省略时，播放到素材末尾或影片结束。`gain` 是线性增益，默认 1。
- 每段重叠时会相加。先在预览试听对白是否听得清。调整各段增益，留出峰值余量。
- 预览点「播放」从开头开始。拖动帧滑块会停止播放，可检查该帧口形。音频与字体加载完成后再开始导出。
- 导出需要浏览器同时支持 VP8 和原生 Opus 编码。OpenAI 或其他服务生成的语音，可先作为本地音频素材准备。这个模板可离线混音、导出有声 WebM。

## 对齐口型

1. 在实际录音中标记每个可辨认口形的起止秒数。语音服务若提供口形或音素事件，可作为时间参考。听一遍实际输出，复核首尾和停顿。
2. 换算到影片时间。片内时间等于 `at + 素材内时间 - offset`。超出本次裁切范围的提示应拿掉。每声部使用独立的口形表。
3. 导出画面时取 `frame / fps`，选择对应口形。让停顿回到常态口形。需要精细表演时，按实际语言画口形变化，允许跨帧保持，避免让嘴跟随文字逐字机械跳动。
4. 抽查第一句、交接与最后一句。查看音轨时长及有声起点，比较成片与预览。若替换了录音，重新测时并更新口形。

语音合成、音素识别与自动口形对齐由素材流程提供。内置样片使用关键时间手工标注。影片时长仍由总帧数和帧率决定。若要多条可分别开关的音轨，或需要 MP4，使用相应的封装流程。
