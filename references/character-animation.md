# 人物动画

人物画面的质量取决于角色素材与动作设计。先选一小段对白或一个动作，在同一镜里做出可辨认的姿势变化，再扩展其他镜头。

## 准备角色与分镜

- 为原创角色确定正面、四分之三侧面和侧面。保留发饰、衣扣和手持物的左右位置。需要看到背面或被遮住的侧面时，另画对应视角。
- 小表情可以只分眼睛、嘴、前后发和身体。走路、转身、交接道具需要额外的关键姿势。保留每层的关节轴心、手掌握点、脚底接地点和比例。
- 每镜标记起止帧、角色朝向、视线、关键姿势和声音落点。先并排看开镜、接触和结束三张静帧。角色与道具的位置、视线方向和阴影要接得上。
- 手绘或用户提供的透明立绘可在 `film.prepare` 中载入与解码，再按帧组合。已有逐镜动画时，可以把画面准备成与成片帧率一致的编号图像，再按帧选图。短段可预解码，中长段按章节处理。直接给播放器一个 MP4 或 WebM 需要另外实现视频取帧，不能依赖 `video.play()` 或浏览器实时时钟决定导出画面。

## 动作和接触

| 动作 | 先定什么 | 看哪几帧 |
| --- | --- | --- |
| 走路 | 先排接触、压低、经过、抬高四类姿势。写清哪只脚在何时离地、在哪里落下。以支撑脚为基准调整骨盆偏移和高度，再补手臂摆动、脚掌角度和衣发跟随。 | 接触帧前后检查脚底滑动、穿地、膝盖反向和身高突变。 |
| 转身 | 用侧面、四分之三侧面、正面等离散画片切换轮廓。分别给头、胸和髋设置动作落点。先看向目标，再让躯干跟上。对称的素材可镜像，发饰和文字单独绘制。 | 核对转身时眼鼻的遮挡、脚底支撑、左右细节和道具朝向。 |
| 双人互动 | 在世界坐标写一个共享握点。两只手各自从原位到同一接触点。给几帧共同接触，再交换道具归属并释放原角色的手。道具位置和旋转沿同一条轨道连续变化。 | 检查到达、交接、释放前后各一帧。手和道具不得穿过彼此，握点不能在换归属时跳位。 |
| 对白与口型 | 先确定录音或合成语音的最终版本，再从实际声音标记闭口、张口、圆口、横向口形与停顿。不同语言可以定义各自的口形表。 | 听清开口、收口与停顿。逐帧查看接话和反应。两人各有口形轨，只让说话的人动嘴。 |

## 验收人体姿势

- 先检查站立和转身中间帧。双肩各接一条手臂，保留两条肩、肘、腕链，即使其中一只手闲置。按镜头的远近顺序绘制手臂和躯干。侧面可以遮住远侧手臂，在下一个可见视角核对它能正确露出。按解剖左右标记肢体，角色转身时持物手的身份保持一致。
- 在角色行走的左右侧视图里，分别检查膝盖是否朝脚尖方向。站立时留出轻微的膝弯。经过步检查骨盆、膝、脚的连线，落地帧检查鞋底接触地面。正面或透视下以对应视角的姿势稿为准。
- 要表现自然步态，可用侧面真人参考对齐脚跟触地、承重、经过和脚尖蹬离。让重心穿过支撑腿，分别给躯干、肩、肘和腕设置时序。单手持物时，单独安排持物手的稳定与空手的摆动。做脚掌滚动时，把实际支点钉在地面上，再算脚踝位置。
- 到达握点和脚底位置的误差只表明末端是否可达。以正常速度播放，再查看起步、支撑、转身中段、双手接触和释放的静帧。手数、关节方向、遮挡和道具归属都应能从成片看出来。

## 按帧取值

通过 `--include assets/character-motion.js` 加载原生 Canvas 示例使用的工具。轨道需按时间排序。位移、旋转和口形都应从当前帧独立求值。

- `poseAt(keys, frame)` 对完整的数值姿势插值。每项为 `{frame, pose:{x,y,...}, easing}`。后一个关键帧可以指定 `linear` 或 `hold`，省略时平滑过渡。各关键帧须使用同一组数值属性。
- `celAt(keys, frame)` 保持上一个离散值。每项为 `{frame,value}`，适合视角画片、表情或道具归属。
- `footAt(frame, planted, swings)` 在离地和落地之间移动一只脚，其余时间保持地面位置。`swings` 的每项为 `{from,to,x,height}`，按帧记录起跳、落地、落点和抬脚高度。
- `limb(root,target,upper,lower,bend)` 按几何侧选取两段链的关节。`bend` 为 `1` 时使用根到目标向量的法向 `(-dy,dx)`。需要按可见方向放关节时，用 `limbToward(root,target,upper,lower,{x,y})`。例如 Canvas 的纵坐标向下，向右的侧视膝盖用 `{x:1,y:0}`，向左用 `{x:-1,y:0}`。两者都返回 `joint`、`end` 和 `error`。接触镜头中，误差应接近零。超出可达距离时先修角色站位或目标。
- `mouthAt(cues,frame,fps)` 按片内秒数查找口形。`{from,to,shape}` 右边界不包含，静默返回 `rest`。渲染可以按需绘制 `small/open/wide/round/closed`，也可用自定义口形。参考 [对白与音轨](audio.md) 对齐时间。

## 运行《借伞》

`assets/character-dialogue.scene.js` 用两位原创简笔角色示范脚底接地、分视角转身、共享握点与双人对白。动画素材是内置 Canvas 画片。对白 WAV 为本机合成示例，口形按已录出的声音手工标注。将画片换成项目的角色稿，再按对应的比例调整关节长度与接触点。

在技能目录运行：

```powershell
node scripts/build.mjs assets/character-dialogue.scene.js ./preview/umbrella.html --include assets/character-motion.js --audio offer=assets/dialogue-audio/offer.wav --audio thanks=assets/dialogue-audio/thanks.wav
node scripts/export.mjs ./preview/umbrella.html ./preview/umbrella.webm
```

把分镜、角色图层、口形表、声音和时间轴一起交付时，生成的 HTML 可直接离线预览。换镜头素材时保留调用约定，逐帧取样和导出仍用同一个 `drawFrame`。
